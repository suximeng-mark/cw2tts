# TTS 自动播报器

> 一个用于 [Class Widgets 2](https://cw.rinlit.cn) 的插件：监听课表通知并自动语音播报。

当课表器触发「上课 / 下课 / 预备铃 / 活动 / 放学」等通知时，插件会把通知内容朗读出来，
支持在线神经语音与多种离线引擎，并允许为每个场景自定义朗读文案与音量。

## 功能特性

- **总开关**：一键关闭自动播报（设置页顶部），关闭后不再朗读，但仍可手动试听。
- **自动播报**：订阅 `NotificationAPI.pushed`，收到通知即朗读。
- **多引擎**：`auto` 模式按优先级自动选择，四个后端可热切换：
  - `piper` — **本地离线神经语音**（ONNX 推理，默认首选）。音质接近在线引擎，**断网可用**，
    首次需在设置页点「下载」获取模型（约 100MB，之后完全离线）。
  - `edge` — EdgeTTS 在线神经语音（中文推荐 `XiaoxiaoNeural` / `YunxiNeural`），音质最佳，需联网。
  - `winrt` — Windows 系统内置语音（WinRT `SpeechSynthesizer`），离线可用。
  - `pyttsx3` — 跨平台离线引擎，作为最后的兜底。
- **自动故障转移**：`auto` 模式下某引擎合成失败时，自动切换到下一个可用引擎重试。
- **中文数字朗读**：自动把 `14:30`、`3楼201`、`95.5` 转为中文读法，避免误读为英文数字。
- **语速调节**：0.5×~2.0× 无级调节（仅 Piper 本地引擎生效，在线与系统语音保持原速）。
- **自定义测试文本**：可自行填写试听内容，留空则用默认测试语句。
- **可配置朗读文案**：为 5 种场景分别设置模板，支持变量快速插入与逐条试听。
- **播报范围**：5 种场景可分别开关；带静音标记的通知默认跳过，可手动开启朗读。
- **指定科目不播报**：勾选课表科目即跳过相关通知，支持作用范围选择与手动添加课表外科目的名称。
- **音量 / 语音调节**：设置页内实时调节。
- **关于与更新**：显示版本、作者、插件 ID 与仓库/广场链接，可一键检查插件广场上的新版本。

## 离线朗读（Piper）

`piper` 引擎是本插件的离线朗读器：把文本在本机用神经网络模型合成为语音，
**不上传任何数据、不需要网络**，音质接近在线 EdgeTTS。

- 推理使用 `onnxruntime` 直接运行 Piper ONNX 模型，不引入 GPL-3.0 的 `piper-tts` 包。
- 音素化优先用系统 `espeak-ng`；若系统未安装，会自动回退到 `pypinyin`（音质略降）。
- 模型缓存目录：`%LOCALAPPDATA%\CW2TTS\piper`，在设置页可一键打开。
- 提供两个音色：`zh_CN-huayan-medium`（标准，约 100MB）与 `zh_CN-huayan-x_low`（轻量，老旧机型）。
- 模型需**联网下载一次**，之后永久离线可用。

> Windows 用户若 espeak 音素化不生效，可安装 espeak-ng 并确保其在 `PATH` 中，
> 或设置环境变量 `ESPEAK_PATH` 指向 `espeak-ng.exe`。

## 指定科目不播报

在设置页「播报范围 → 指定科目不播报」中，把课表科目的开关切到「跳过」，
与该科目相关的通知就不会被朗读（手动试听不受影响）。

- 科目名自动从当前课表读取；换课表后点「刷新」重新读取。
- 课表外的科目（如「自习」「班会」）可在输入框手动添加，多个名称用逗号或顿号分隔；
  手动添加的条目会带「移除」按钮。
- 作用范围可选：

  | 选项 | 判定依据 |
  | --- | --- |
  | 当前课或下节课（默认） | 当前科目、下节科目任一命中 |
  | 仅当前科目 | 只看当前科目 |
  | 仅下节课 | 只看下节科目 |

- 匹配忽略大小写与首尾空白；名单项是课表科目名的子串也算命中，
  例如「数学」可覆盖「数学（理科）」。
- 运行时取不到科目信息时，退回按通知标题 + 正文匹配；「放学」通知不做科目过滤。
- 课表改名后旧名单项仍显示为自定义条目，可手动移除。

## 朗读文案模板

在设置页「朗读文案」中，可为每种场景编辑模板，支持以下变量：

| 变量 | 含义 |
| --- | --- |
| `{title}` | 通知标题（如「上课了」） |
| `{message}` | 通知正文 |
| `{subject}` | 当前科目名 |
| `{teacher}` | 当前教师 |
| `{location}` | 当前地点 |
| `{next_subject}` | 下一节科目名 |
| `{next_teacher}` | 下一节教师 |
| `{next_location}` | 下一节地点 |

- 点击「快速插入变量」按钮可把变量插入到光标处，避免手打变量名出错。
- 每个场景可随时「恢复默认」，也可「试听」当前模板效果。

默认模板：

- 上课：`上课了，{subject}`
- 活动：`活动开始，{subject}`
- 课间休息：`下课了，下节课是{next_subject}`
- 放学：`放学了`
- 预备铃：`预备铃，下节课是{next_subject}`

## 依赖说明

本插件的依赖**已随安装包一起分发**，安装后无需额外 `pip install`：

| 依赖 | 用途 | 状态 |
| --- | --- | --- |
| `onnxruntime` | Piper 离线语音推理 | 已内置 |
| `edge-tts` | 在线神经语音 | 已内置 |
| `winrt-*` | Windows 系统语音 | 已内置 |
| `pyttsx3` | 跨平台离线兜底 | 需手动安装 |

> `pyttsx3` 在 Windows 上需拉入 `comtypes` / `pywin32` 并本地构建，
> 会显著拖慢打包且容易失败，因此未内置（Windows 语音已由 `winrt` 覆盖）。
> 非 Windows 平台如需该兜底，可手动 `pip install pyttsx3`。
> 设置页会将其标注为「未安装」。

> 唯一需要单独下载的是 Piper 语音模型（约 100MB），在设置页点「下载」即可，
> 之后完全离线可用。

## 稳定性与权限处理

针对课堂机常见的「无权限导致不播报」：

- 临时音频不再固定写系统 `%TEMP%`：优先 `%LOCALAPPDATA%\CW2TTS\tmp`，启动时做真实读写探测；不可写时依次回退到 TEMP 下的子目录、系统 TEMP。
- 合成时目录写入被拒会自动换下一个候选目录重试；全部不可写才放弃，日志给出具体路径。
- 模型缓存目录同样做真实可写探测并回退；下载失败时设置页显示含目录路径的原因。
- EdgeTTS 返回 403（代理/校园网/公司网络策略）时给出明确文案，不再误读为文件权限不足，并自动转离线引擎。
- 一次合成失败不再清空后续通知队列；`auto` 按 Piper → Edge → WinRT → pyttsx3 逐级转移。
- 播放结束的文件清理改用「播放代数」判定，避免旧播放的停止信号误删正在播放的新音频。
- 音频设备被独占或文件被锁时记录播放错误，便于与文件权限问题区分。

## 安装

1. 在 Class Widgets 2 的插件广场中搜索并安装本插件；或下载 `.cwplugin` 文件手动导入。
2. 依赖已内置于安装包，安装后无需额外配置 Python 环境。
3. 首次进入设置页会自动探测可用引擎。若要使用**离线朗读**，在「离线朗读模型」中点「下载」获取 Piper 模型。

## 开发 / 打包 / 发布

```bash
# 1. 安装 SDK 与依赖（开发模式）
pip install -e .

# 2. 在 Class Widgets 2 本体中调试运行本插件

# 3. 打包为可分发包
python build_pack.py            # 生成 .cwplugin
python build_pack.py --format zip

# 4. 发布：打 tag vX.Y.Z 推送到 GitHub，release.yml 自动构建、
#    发布到插件广场并创建 Release
#    （需先在仓库 Secrets 中配置 CWPT_TOKEN，令牌在广场控制台获取）
git tag v1.2.0 && git push --tags
```
